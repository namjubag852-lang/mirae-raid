# 미래공대 공대원 관리 전용 사이트 — 무료 배포 준비

## 이 패키지는 무엇인가요?
- **분배시트는 포함하지 않습니다.** 공대원 관리만 있는 별도 사이트입니다.
- `index.html`: 공대원 화면, `admin.html`: 관리자 화면.
- Vercel에 올릴 수 있는 **정적 웹사이트 데모**입니다.
- 데모 로그인 정보는 테스트용입니다. **실제 보안 인증이 아닙니다.**
- 현재 입력값은 브라우저 로컬/세션 저장소에 저장되며, 서로 다른 기기 사이에 공유되지 않습니다.
- 실제 개인정보·비밀번호·전화번호를 입력하거나 실사용으로 공개하지 마세요.

## 무료 Vercel 주소 만들기
1. GitHub에 로그인해 새 저장소를 생성합니다(공개/비공개 무관).
2. 이 ZIP을 압축 해제하고 `index.html`, `admin.html`, `vercel.json`을 저장소 최상위에 업로드합니다.
3. https://vercel.com/new 에 로그인하여 `Import Git Repository`에서 저장소를 선택합니다.
4. Framework Preset: `Other`, Root Directory: `./`, Build Command: 비워둠, Output Directory: 비워둠.
5. Deploy를 누르면 `https://...vercel.app` 주소가 생성됩니다.
6. 공대원은 `/`, 관리자는 `/admin` 또는 `/admin.html`로 접속합니다. (환경에 따라 `/admin.html` 사용)

## 정식 운영 전에 필수 작업
- 공유 데이터베이스(예: Supabase) 연결
- 실제 로그인/비밀번호 해시 및 서버에서 관리자·공대별 권한 검증
- 전화번호와 인증 사진 접근 제한, 스토리지 및 백업 설정
- 가입 승인, 참여/대타/손님 구인, 트라이 완료 기록을 서버에 저장
- 여러 기기 동시 테스트

Vercel 계정에 대한 로그인/배포 버튼 클릭은 계정 소유자가 직접 진행해야 합니다.
