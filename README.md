# 미래공대 원본 디자인 복원 + Supabase 연결

- 원본 `style.css` 기반의 좌측 메뉴/색상/카드 디자인을 복원했습니다.
- Supabase 회원가입·로그인·승인·권한·참여 체크·대타·트라이 완료·프로필 정보 저장을 연결합니다.
- 손님 구인, 인증 사진, 아이템 획득 사진은 현재 DB에 테이블/스토리지/보안 정책이 없어 **서버 저장 미지원**으로 표시합니다. 원본 기능 완전 복구본이 아닙니다.
- 원본 통합 분배시트는 서버 저장 연결이 없어 이 패키지에 포함하지 않았습니다.
- GitHub 루트에 ZIP 내부 파일들을 올리고 Vercel 자동 배포합니다. 기존 Supabase SQL을 재실행하지 마세요.
- config.js는 공개 가능한 publishable key만 사용합니다.
